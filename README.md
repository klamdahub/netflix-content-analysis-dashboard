# netflix-content-analysis-dashboard
Netflix Content analysis dashboard that was created on Excel using public kaggle dataset.

Key Findings
- Netflix adds more movies (71% of all content) than TV Shows (21%)
- Most content falls under TV - MA rating, meaning it is meant for those 17 years and older
- Most content were from the early 2000's to 2010's
- Most content were produced in the United States
- Dramas, International Movies was the top genre

Tools Used
- Excel: pivot charts, IF Function, Power Query
- Skills: data cleansing, data visualization
